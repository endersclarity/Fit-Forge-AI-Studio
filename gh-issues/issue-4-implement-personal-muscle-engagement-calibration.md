## Problem
FitForge uses default muscle engagement percentages for all users, but everyone's body is different (leverages, form, mind-muscle connection).

## Solution
Enable users to override default muscle engagement percentages based on their personal biomechanics:
- View and adjust muscle engagement percentages for any exercise
- Use intuitive sliders (0-100%) for each muscle group
- See real-time preview of how changes affect recommendations
- Reset to defaults if needed
- Mark exercises as "Calibrated" vs "Default"
